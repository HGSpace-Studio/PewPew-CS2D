# PewPew 游戏

## 游戏简介

PewPew是一款用Java开发的2D射击游戏，具有丰富的游戏特色和独特的游戏机制。游戏采用随机生成地图的方式，让玩家每次游戏都能体验到不同的游戏环境。

## 游戏特色

- **多种武器系统**：包括格洛克手枪、M4步枪、AWP狙击枪、霰弹枪、光剑和传送枪（类似Portal游戏中的传送武器）
- **随机生成地图**：采用区块（Chunk）系统，类似Minecraft的地形生成方式，每次进入新区域都会自动生成新的地图
- **敌人AI**：游戏中会生成机器人敌人，与玩家进行战斗
- **连击系统**：包含双杀、三杀、超神杀、超级杀、怪物杀、神一般等连击奖励
- **控制台命令**：提供多种游戏控制命令，如无敌模式、无限弹药、一击必杀等
## 操作说明

### 基本移动
- **W**：向前移动
- **A**：向左移动
- **S**：向后移动
- **D**：向右移动
- **方向键**：控制相机移动

### 武器操作
- **1-6**：切换武器
  - 1：格洛克手枪
  - 2：M4步枪
  - 3：AWP狙击枪
  - 4：霰弹枪
  - 5：光剑
  - 6：传送枪
- **空格键**：开火
- **R**：重新装填
- **Shift**：扔手雷

### 其他控制
- **Y**：锁定屏幕
- **Ctrl**：切换相机跟随模式
- **Esc**：退出游戏
- **`**（反引号）：打开控制台

## 控制台命令

按 ` 键打开控制台，输入以下命令：

- **godmode**：开启/关闭无敌模式
- **ammo** 或 **unlimited ammo**：开启/关闭无限弹药
- **kill** 或 **nuke**：杀死所有机器人
- **clear** 或 **clear map**：清除地图上的实体
- **suicide**：自杀
- **1hit** 或 **onehit** 或 **one hit**：开启/关闭一击必杀
- **size**：显示当前实体数量
- **boxes**：显示/隐藏碰撞框
- **fps** 或 **showfps** 或 **togglefps**：显示/隐藏FPS和位置信息
- **spawn <数量> <半径>**：在玩家周围生成指定数量的机器人
- **teleport <列> <行>**：传送到指定位置

## 安装和运行

### 方法一：直接运行JAR文件
1. 确保您的电脑已安装Java运行环境（JRE 1.8或更高版本）
2. 双击 `PewPewv2.jar` 文件即可运行游戏

### 方法二：使用批处理文件
1. 双击 `run_game.bat` 文件运行游戏
2. 游戏退出后会自动暂停，按任意键关闭窗口

### 方法三：生成EXE文件（需要Launch4j）
1. 安装Launch4j工具
2. 运行Launch4j GUI
3. 点击"File" → "Load Config"，选择 `pewpew.xml` 配置文件
4. 点击"Build Wrapper"按钮生成 `PewPew.exe` 文件
5. 双击 `PewPew.exe` 文件运行游戏
